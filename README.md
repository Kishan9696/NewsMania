# 📰 NewsMania

NewsMania is a modern news application that fetches the latest news in real-time using APIs.  
It provides news from multiple sectors like Technology, Sports, Business, Entertainment, Health, Science, and more with support for multiple languages for a personalized news reading experience.

---

## 🚀 Features

  - Multi-language news support
  - Latest real-time news updates using APIs
  - News categories/sectors support
  - Technology
  - Sports
  - Business
  - Entertainment
  - Health
  - Science
  - General News
- 🔍 Search functionality
- 📱 Responsive user interface
- ⚡ Fast and dynamic content loading
- 🌙 Clean and user-friendly design
